MI DÍA — PWA inicial (v0.1)

Incluye interfaz oscura y módulos de tráfico, tiempo, FCF y extras.
Aún no consulta datos reales ni envía notificaciones automáticas.

CÓMO USAR DESDE EL MÓVIL
1. Este ZIP debe publicarse en un hosting HTTPS (por ejemplo GitHub Pages).
2. Cuando esté publicado, abre la URL en Chrome para Android.
3. Menú ⋮ > Instalar aplicación (o Añadir a pantalla de inicio).
4. La app aparecerá con el nombre y el icono Mi Día.

IMPORTANTE
No se puede instalar como PWA directamente abriendo index.html desde el ZIP:
para una instalación correcta, debe servirse desde una dirección HTTPS.
